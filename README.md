# Terminal Toolkit

A practical collection of **essential Bash and terminal commands for software engineers**.

This repository is a personal reference for learning and revising the commands that are commonly used in day-to-day software development, debugging, and working with the command line.

## What's Covered

The repository currently covers:

* 📁 **Navigation** — moving around directories and working with paths
* 📄 **Files** — creating, copying, moving, and managing files
* 📖 **Reading Files** — viewing and inspecting file contents
* 🔍 **Searching** — finding files and searching through code and logs
* ✍️ **Writing Files** — writing, appending, and redirecting command output
* 🔗 **Pipes** — connecting commands together to build useful workflows
* 🗜️ **Compression** — working with ZIP, TAR, and compressed archives
* ⚙️ **Processes** — inspecting and managing running processes
* 🌐 **Networking** — testing connectivity, APIs, DNS, SSH, and file transfers
* 🔀 **Command Chaining** — combining commands using operators such as `&&`, `||`, and `;`

Each section contains **commonly used commands, their purpose, and practical examples** to make them easier to understand and apply.

## 🎯 Goal

The goal of **Terminal Toolkit** is to build a simple, practical reference for software engineers who want to become more comfortable and productive with the terminal.

Rather than covering every available command, this repository focuses on commands that are **useful in real-world development and debugging**.

## 🚀 Usage

Use this repository as a quick reference while learning or working on real projects.

```bash
git clone https://github.com/shishir2305/terminal-toolkit.git
cd terminal-toolkit
```

Explore the sections based on what you need, try the commands locally, and gradually build your command-line toolkit.
